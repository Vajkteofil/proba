# 3D nyomtatás — landing page

Design canvas forrásfájljai. Minden `.dc.html` egy artboard, a `canvas.json` az elrendezés.

- `Main.dc.html` — asztali landing page (1440px)
- `Mobile.dc.html` — mobil változat (390px)
- `DirectionB.dc.html`, `DirectionC.dc.html` — alternatív irányvázlatok

Élő canvas: https://claude.ai/code/artifact/fe55ec2b-f4a2-47e1-ad82-5247f1f3c0f5

A `[szögletes zárójeles]` értékek helyőrzők — valós céges adatra kell cserélni őket.
